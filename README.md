# Swiggy-Food-Delivery-Data-Analysis-Dashboard-
This project analyzes 3,060 cleaned FY 2025 Swiggy food delivery orders (60 duplicate records removed) across 10 Indian cities (Bengaluru, Delhi, Mumbai, Hyderabad, Chennai, Pune, Kolkata, Ahmedabad, Jaipur, and Lucknow) and 10 food categories in alignment with the SapphireIQ analytics brief.
